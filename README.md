# 🌸 Madhav Online Center (माधव ऑनलाइन सेंटर)

> **सभी सरकारी एवं ऑनलाइन सेवाएं एक ही काउंटर पर | Belipar, Gorakhpur**

Official responsive website for **Madhav Online Center**, located at Bistauli Khurd, Belipar, Gorakhpur (Near HP Petrol Pump, National Highway 27).

---

## 📌 Project Overview
A fast, lightweight, and modern web application built using semantic **HTML5**, **CSS3**, and vanilla **JavaScript**. Crafted with divine **Lord Krishna** motif and custom SVG branding.

### ✨ Key Features
1. **Divine Lord Krishna Branding:**
   - Custom SVG emblem with Lord Krishna playing the flute, peacock feather (Mor Pankh), crown, and tilak.
   - Matching browser favicon.

2. **Services Mega Menu (40+ Services):**
   - Categorized directory: Certificates & e-District, Identity & Smart Cards, Pensions & Schemes, Travel & Ticketing, Banking & Bills, Education & Job Forms.
   - Real-time search filter for instant lookups.
   - One-click inquiry links directly connecting to WhatsApp.

3. **Navbar Contact & Service Request Modal:**
   - Interactive modal application form accessible from the navbar.
   - Form fields for Name, 10-digit Phone Number, Service Selection, and Request Details.
   - Validates user input and formats a pre-filled WhatsApp message sent directly to `+91 7355788684`.

4. **Floating Circular WhatsApp Chatbot Widget:**
   - Single circular floating action widget visible continuously from the Hero section down to the Footer.
   - Includes radar ripple pulse animation, live green online status dot, and interactive greeting bubble.

5. **Design & Responsiveness:**
   - High fidelity to original design mockup.
   - Fully responsive on mobile, tablet, laptop, and desktop screens.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic, accessible markup.
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, keyframe animations, mobile-first responsiveness.
- **JavaScript (ES6+):** Pure vanilla JavaScript (zero dependencies).
- **Icons & Graphics:** Scalable Vector Graphics (SVG).

```bash

python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
